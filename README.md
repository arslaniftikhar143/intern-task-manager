# Intern-Task-Manager
This is MERN web app created for practicing crud using React on frontend and Express Node on backend using Mongodb database. 

## Instructions to run this project
Clone this project. 

## Requirements
Add the required variables in .env file. You should have Node and Git installed on your system.

### Install dependencies
Open two terminals and move to frontend and backend folders. run `npm i` command in both terminals. 

### Run Project
After installing required packages run `npm start` in terminal opend in root directory. It automatically run the Frontend on 5173 port and backend on 3000 port.
